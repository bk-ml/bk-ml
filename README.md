## 🔥 Featured System

### 🎤 Real-time Voice AI System

<p align="center">
Mic → STT → LLM → TTS → Audio
</p>

A streaming-first architecture designed for **conversation-like responsiveness**, not batch processing.

**Key engineering decisions:**

- 🔄 Migrated batch pipeline → streaming architecture
- ⏱️ Identified TTS as dominant latency bottleneck (~40× slower than LLM)
- 🧠 Optimized synchronization across async components
- 🎯 Focused on perceived latency (not just compute latency)

> ⚡ Result: A system that feels like real conversation, not request-response cycles.

---

## 🌐 System Design Philosophy

<p align="center">
<b>End-to-end behavior > isolated component performance</b>
</p>

- 🧠 Treat frontend + backend as one continuous system
- 🔁 Design for failure, retries, and partial system breakdowns
- ⚡ Optimize perceived latency, not just backend speed
- 🧩 Prefer simple systems that scale over complex fragile ones
- 📡 Build for real-world chaos, not ideal conditions
